## **1.这个 Skill 解决什么科研问题？**

- 本 Skill 面向科研文献调研场景，帮助研究生快速获取某一研究方向的代表性论文，并自动生成结构化分析报告。

  在科研过程中，无论是开题、中期研究还是论文撰写，都需要大量阅读相关领域文献。

  然而研究生通常会遇到以下问题：

  1. 检索论文耗时较长；
  2. 难以快速判断论文是否与研究方向相关；
  3. 阅读多篇论文后难以形成系统总结；
  4. 不同论文之间的研究思路难以比较。

  如果没有该 Skill，研究人员通常需要：

  - 手动在 arXiv 搜索论文；
  - 下载并阅读大量 PDF；
  - 自己整理论文摘要；
  - 比较不同论文的方法和贡献；
  - 编写文献综述笔记。

  因此，本 Skill 希望将文献调研过程标准化和自动化。

  输入为研究主题关键词；输出为结构化论文分析报告。

  

## 2. 它和普通 ChatGPT 问答有什么区别？

| 对比项   | 普通 ChatGPT 问答 | 本 Skill                    |
| -------- | ----------------- | --------------------------- |
| 任务目标 | 回答单个问题      | 完成完整文献调研流程        |
| 输入材料 | 自然语言问题      | 指定研究主题关键词          |
| 分析流程 | 不固定            | 固定检索→下载→解析→汇总流程 |
| 输出格式 | 自由生成          | 结构化论文分析报告          |
| 可复用性 | 依赖用户提问能力  | 任意用户均可复用            |
| 可验证性 | 较弱              | 可对应原始论文内容验证      |

本 Skill 的核心价值不在于让大模型回答问题，而在于把科研文献调研这一高频任务转化为标准化工作流。

用户只需提供研究主题，即可自动完成：

- arXiv 检索
- 论文下载
- 内容解析
- 论文比较
- 报告生成

整个流程无需人工干预。

# 3. 它的输出怎么验证？

为了保证分析结果可信，本 Skill 输出中会保留论文来源信息。

验证方式如下：

### （1）结论是否对应原始论文

每条分析结论均对应具体论文。

例如：

| 结论                              | 证据来源     |
| --------------------------------- | ------------ |
| Vision Transformer 已成为主流结构 | Paper 0 摘要 |
| 大多数方法采用自监督预训练        | Paper 1 摘要 |
| 多模态融合是当前研究热点          | Paper 2 摘要 |

### （2）是否标明证据来源

输出中记录：

- 论文标题，作者，arXiv链接，摘要内容，可回溯验证。

### （3）区分事实与推测

Skill 输出包括：事实结论：来自论文摘要的直接信息。综合分析：由大模型根据多篇论文进行归纳。两部分明确区分。

### （5）是否可复查

任何同学均可：使用相同关键词；获取相同论文；对照论文摘要；验证分析结果。因此具有较好的可验证性。



# 4. 输入、输出和工作流程

## 4.1 输入材料

本 Skill 的输入包括：

- 研究主题关键词

例如：

- Object Detection
- Visual Tracking
- Diffusion Model
- Medical Image Segmentation
- Large Language Model

## 4.2 输出结果

Skill 输出：

- Top-5相关论文列表
- 论文元数据
- 论文摘要
- 多论文综合分析报告

## 5.3 工作流程

### Step 1:接收用户研究主题:例如："Object Detection"

### Step 2:调用 arXiv API检索相关论文

### Step 3：下载论文PDF保存到：paper_0.pdf,paper_1.pdfpaper_2.pdf

### Step 4：解析论文内容提取：标题作者摘要

### Step 5：构建统一分析文本，合并多篇论文信息

### Step 6：输出结构化报告并保存结果。

本 Skill 的特色主要体现在：

# 8. 局限性和改进方向

目前存在以下局限：

1. 主要依赖 arXiv 数据源；
2. 只解析论文摘要，未深入分析全文；
3. 对跨领域研究支持有限；
4. 尚未实现引文网络分析；
5. 大模型分析可能存在偏差。

未来计划：

- 支持 Semantic Scholar；

- 支持 Google Scholar；

- 支持全文PDF解析；

- 增加引用关系分析；

- 增加研究趋势可视化。

# 10. 总结

本组开发的 Paper Analysis Skill 面向科研文献调研场景，能够自动检索 arXiv 论文、下载 PDF、提取论文内容并生成结构化分析报告。与普通 ChatGPT 问答相比，本 Skill 具有明确输入、固定工作流程和统一输出格式，能够将科研文献调研任务标准化。输出结果可通过论文摘要和原始论文进行验证，从而提高分析结果的可信度。未来可进一步扩展全文解析、引文分析和研究趋势挖掘等高级功能，提升科研辅助能力。
